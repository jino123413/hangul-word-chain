# 끝말잇기 챌린지

앱인토스 웹뷰 미니앱입니다. 혼자 모드로 끝말잇기를 플레이할 수 있습니다.

## 핵심 기능

- 오늘의 시작 단어 기반 끝말잇기
- 대중 룰 기반 검증 (2글자 이상, 중복 금지, 앞글자 연결)
- 일일 챌린지, 최고 기록, 단어 컬렉션
- 선택형 광고 기능 (AD 배지 + 사전 안내)

## 실행

```bash
npm install --legacy-peer-deps
npm run dev
```

## 빌드

```bash
npm run build
```

## 앱 설정

- appName: `hangul-word-chain`
- displayName: `끝말잇기 챌린지`
- primaryColor: `#155E75`
