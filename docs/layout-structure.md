# 끝말잇기 챌린지 레이아웃 구조 (릴레이 트랙형)

## 1) 구조 콘셉트

- 주제 매칭: 끝말잇기를 "단어 바통 전달" 릴레이로 해석
- 배치 원칙: 상단 요약 + 중앙 세로 트랙 + 우측 대시보드 + 하단 타임라인
- 여백 처리: 빈 박스 대신 트랙 구간/상태/통계 슬롯으로 채움

## 2) 메인 화면 ASCII

```text
┌────────────────────────────────────────────────────────────┐
│ 혼자 모드 · 릴레이 트랙    끝말잇기 챌린지    오늘 씨앗단어 │
├────────────────────────────────────────────────────────────┤
│                      │                                      │
│  [트랙 구간 1]       │   [오늘의 챌린지]                    │
│  현재 글자 + 입력창  │   목표 문구 + 진행률 바              │
│  [연결] 버튼          │                                      │
│        │              │   [트랙 대시보드]                    │
│  [트랙 구간 2]       │   현재점수 / 오늘최고 / 역대최고      │
│  내 최근 단어         │   수집개수 / 전체플레이 / 누적단어    │
│  상대 최근 단어       │                                      │
│  다음 목표 글자       │                                      │
│        │              │                                      │
│  [트랙 구간 3]       │                                      │
│  상태 메시지          │                                      │
│  [이번 판 종료]       │                                      │
│  (종료 시) [AD]이어하기│                                     │
├────────────────────────────────────────────────────────────┤
│ 최근 릴레이 타임라인 (최근 8턴: 시스템/나/상대 순서 칩)      │
└────────────────────────────────────────────────────────────┘
```

## 3) 구간별 UX 의도

### 구간 1: 입력
- 플레이어가 지금 해야 할 행동(현재 글자 -> 단어 입력 -> 연결)을 가장 먼저 노출

### 구간 2: 응답 확인
- 내 단어, 상대 단어, 다음 목표 글자를 한 덩어리로 묶어 판단 속도 향상

### 구간 3: 판정/다음 행동
- 상태 메시지와 행동 버튼(종료/재시작/AD 이어하기)을 같은 블록에 배치

### 사이드 대시보드
- 챌린지와 핵심 지표를 오른쪽 고정 슬롯으로 분리해 주의 분산 감소

### 하단 타임라인
- 최근 8턴을 칩으로 압축해 흐름 복기 시간을 줄임

## 4) 광고 정책 반영

- 핵심 기능(입력/연결/기본 진행): 광고 없음
- 광고 노출 지점: 라운드 종료 후 선택형 "이어하기" 1회
- 버튼 표기: AD 배지 + 사전 고지 문구
